# 학습자료 파일 저장 원칙

대학 논술 가이드북, 기출 자료, 압축 파일 등 대용량 원본 학습자료는 코드 저장소·배포 번들에 포함하지 않습니다. 프로젝트 루트의 `학습자료/` 경로는 Git 무시 대상이며, 개발·배포 작업 폴더에 다시 복사하지 않습니다.

원본 자료가 학습자 화면에서 필요할 때는 관리 화면의 **File Storage**에 업로드하고, 애플리케이션에는 파일 자체가 아닌 저장소 URL과 제목·출처·과정·공개 상태 메타데이터만 저장합니다. 파일 바이트는 S3 파일 저장소가 단일 원본이며, 데이터베이스는 검색·권한·표시용 메타데이터만 보관합니다.

현재 원본 자료는 배포 대상 밖의 `/home/ubuntu/webdev-static-assets/essay-master-learning-materials-20260822/`에 보존되어 있습니다. 이 경로는 개발 보관용이므로 배포 화면에서 직접 참조하지 않습니다. 다시 제공할 자료는 반드시 File Storage에 개별 업로드한 뒤 생성된 URL을 사용합니다.

## 재업로드 확인 절차

1. 관리 화면의 File Storage에서 필요한 PDF 또는 ZIP을 업로드합니다.
2. 제목, 출처, 대상 과정, 공개 범위, 자료 유형을 기록합니다.
3. 학습자 화면에는 저장소 URL만 연결하고, 권한 없는 사용자에게는 파일 URL을 노출하지 않습니다.
4. 배포 전 `git ls-files -- 학습자료`의 결과가 비어 있는지와 `pnpm git:sync:check`가 통과하는지 확인합니다.
