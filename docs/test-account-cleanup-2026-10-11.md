## AI 첨삭 전용 봇 판정

`getDefaultAiTutor()`는 기본 담당자를 반환하며, 회원가입에서 교사를 고르지 않은 학생과 마이페이지에서 AI 담당을 선택한 학생을 이 계정에 연결한다. 봇 계정 자체에 별도의 자동 실행 작업이나 독립 모델이 붙어 있는 구조는 아니다.

실제 AI 평가는 `aiAutoFeedback.create` 등의 서버 절차에서 `evaluateWritingWithLLM()`을 호출해 실행한다. 봇 계정에 교사 첨삭 실적이 없다는 이유만으로 삭제하면 기본 담당자 연결에 영향을 줄 수 있고, 다음 가입 시 다시 생성된다. 따라서 기본 담당 봇은 보존했다.

실제 DB에서 기본 담당 봇의 ID·이름 반환을 검증했다. 해당 조회는 AI 모델을 호출하지 않는다. 이번 계정 정리에서는 유료 또는 실제 LLM 호출 성공을 새로 검증한 것은 아니다.

## 운영 스크립트

파일: `scripts/cleanup-approved-test-accounts.mjs`

기본 실행은 삭제하지 않고 계획만 출력한다.

```bash
node scripts/cleanup-approved-test-accounts.mjs
```

실제 삭제는 출력된 계획 해시를 명시해야 한다.

```bash
node scripts/cleanup-approved-test-accounts.mjs --apply --plan-sha=<읽기 전용 계획의 planSha>
```

이 스크립트는 이번에 승인된 계정의 고정 ID·이메일 쌍만 대상으로 한다. 다른 계정을 추가하려면 새 삭제 목록을 검토하고 사용자의 별도 승인을 받아야 한다. `.env`를 읽거나 DB 접속 정보·비밀번호·학습 원문을 출력하지 않는다.

코드 체크포인트는 DB 삭제 데이터를 복구하는 백업이 아니다. 이번 삭제 데이터의 별도 원문 복사본은 생성하지 않았다. 삭제된 이메일 또는 소셜 계정으로 새로 가입하면 새로운 회원 기록이 생성될 수 있으며, 이번 작업은 재가입 차단 기능이 아니다.
