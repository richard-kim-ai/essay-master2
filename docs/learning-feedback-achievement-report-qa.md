# 학습 피드백·성취 요약 리포트 QA

워크북의 확인문제는 저장 중에는 회전 표시와 **저장 중** 문구를, 저장 성공 뒤에는 **저장 완료** 문구와 초록 안내문을 보여 준다. 레슨 탭·이전·다음 이동은 선행 레슨의 완료 기록을 요구하지 않으며, 레슨 범위를 벗어난 이동만 안전하게 보정한다.

성취 요약 리포트는 현재 화면을 인쇄하지 않는다. 과정·전체 진도, 평균 점수, 퀴즈 정답률, 학습 일수, 수료증·뱃지 현황과 진도·성장·능력 차트를 별도 캔버스 한 장에 그린 뒤 해당 결과만 가로형 PDF로 저장한다.

모바일 화면에서도 레슨 탭은 가로 스크롤로 유지되고 자유 이동 안내가 확인되며, 성취 갤러리의 PDF 저장 진입 버튼과 핵심 지표가 좁은 폭에서 카드 형태로 표시되는 것을 확인했다.
