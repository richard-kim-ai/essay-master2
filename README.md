# ✍️ 논술 마스터 (Essay Master)

> AI 기반 논술 교육 플랫폼 – 기초부터 실전까지 단계별 학습

## 프로젝트 소개

**논술 마스터(Essay Master)**는 『논술의 기초』 교재를 기반으로 한 AI 학습 플랫폼입니다.
문장 → 단락 → 요약 → 주제 설정 → 실전 논술까지 체계적인 학습을 제공하며,
AI 피드백과 활동 중심 학습을 통해 논리적 글쓰기 능력을 향상시키는 것을 목표로 합니다.

본 프로젝트는 기존 기획안, 통합 기획안, README 초안을 통합하여 정리한 문서입니다.

---

# 핵심 목표

- 교재 기반 디지털 학습
- AI 실시간 피드백
- 단계별 실습 중심 교육
- 개인 맞춤 학습관리

- 논술 입문자

- 대학 입시 준비생
- 글쓰기 역량 향상이 필요한 일반인

# 교육과정

## 초등 과정

| Level | 내용 |
|-------|------|
|1|낱말과 문장|
|2|이야기 만들기|
|3|생각 정리 및 요약|
|4|창의적 글쓰기|

## 중·고등 과정

| Level | 내용 |
|-------|------|
|1|문장의 기초|
|2|단락 구성과 논리|
|3|구조 분석 및 요약|
|4|비판적 사고와 실전 논술|
